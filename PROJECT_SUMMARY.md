# Project Summary

## Problem
Financial messages can combine unrealistic returns, urgency, payment pressure and authority cues. A first-time user may find it difficult to understand why a message deserves verification.

## Solution
NiveshRakshak converts a message or screenshot into an explainable set of risk indicators. The product focuses on awareness and verification rather than investment recommendations.

## Unique points
1. Screenshot-to-analysis flow with local OCR.
2. English + Hindi OCR and language detection.
3. Explainable signals instead of a black-box verdict.
4. Anonymous session history backed by a database.
5. Privacy-aware architecture: screenshots never reach the backend.
6. Safety-first positioning: no buy/sell recommendations.

## Tech stack
- Frontend: HTML, CSS, JavaScript
- OCR: Tesseract.js
- Backend: Node.js + Express
- Database: PostgreSQL
- Security middleware: Helmet, CORS, rate limiting
- Deployment: Render / Docker
